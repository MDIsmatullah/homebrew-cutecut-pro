# Homebrew Tap for CuteCut Pro

Official Homebrew Cask tap for **CuteCut Pro** — Professional Multitrack Video Editor & Quran Recitation Studio for macOS.

## Installation

To install CuteCut Pro using [Homebrew](https://brew.sh/), run the following commands in your Terminal:

```bash
brew tap MDIsmatullah/cutecut-pro
brew install --cask cutecut-pro
brew upgrade --cask cutecut-pro
brew uninstall --zap --cask cutecut-pro
